# Capability-Led Growth

> 当 AI 能力可以被拆分、调用、复制和分发，它就可能成为增长载体。

Capability-Led Growth（CLG，能力驱动增长）是一种面向 AI-native 产品的
GTM motion：企业将产品或专业服务中的一部分真实能力，封装为可独立使用、可分发的
能力单元，让潜在用户在进入完整产品之前先获得实际结果，并由能力使用推动发现、
激活、转化与扩张。

这不是一个已经被市场充分验证的标准术语，而是从一个真实项目中产生的模型假设。
本仓库用于公开阐述、质疑和迭代这一模型。

## 一句话模型

```text
传统 GTM：先传播主张，再邀请用户体验能力

PLG：让用户进入产品，通过产品使用推动增长

CLG：把部分产品能力送入用户已有环境，
     让能力使用本身完成价值证明并推动增长
```

## 当前判断

CLG 最适合以下场景：

1. 企业拥有能够被切分并独立交付价值的能力。
2. 能力单元可以低摩擦进入潜在用户已有工作环境。
3. 首次使用可以产生可感知、可信的结果。
4. 免费能力与完整产品或付费服务之间存在自然连续性。
5. 分发、使用和后续转化能够被衡量。

CLG 不等于免费工具、内容营销、带广告的 Skill，也不等于把 Skill、MCP 和 Agent
粗暴归为同一种载体。

## 起源

这一模型来自两个实验项目：

- `enterprise-ai-scenario-analyzer`：一个可分发的企业 AI 场景分析 Skill，
  也是最初的发现来源。
- `skill-asset-operations-tool`：对 Skill 的归属、转化和分发包装进行探索的
  早期工具。
